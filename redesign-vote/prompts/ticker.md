# 09. ticker — Финансовый терминал

Бриф, который получил субагент этой концепции (поверх [общего каркаса](README.md)).

**Результат:** [главная](https://redesign-vote-production.up.railway.app/ticker/index.html) · [статья](https://redesign-vote-production.up.railway.app/ticker/post.html)

## Бриф

Bloomberg Terminal. Чёрный фон, фирменный янтарный/оранжевый текст (+ зелёный рост / красный падение для дельт), плотный моноширинный шрифт с кириллицей (IBM Plex Mono / PT Mono). Сверху — бегущий тикер моделей с ценами (CSS marquee-анимация): FBL5 $10/$50 ▲NEW · OPUS 4.8 $5/$25 · SONNET 4.6 $3/$15 · HAIKU 4.5 $1/$5 · GPT-5.5 $5/$30 · GPT-5.5-PRO $30/$180 · GEMINI 3.1 PRO $2/$12. Экран разбит на плотные панели с заголовками-кодами (BLOG <GO>, VID <GO>, LINKS <GO>): посты — как лента сделок с timestamp, видео — как котировки. Командная строка, ряд функциональных клавиш F1–F10 внизу с подписями разделов. Timestamp везде. Числам — табличная выключка. Пост — терминальный «RESEARCH REPORT»: шапка отчёта (тикер FBL5, дата, аналитик RIS), таблицы цен как биржевые с подсветкой, CSS-bar-chart сравнения цен моделей, промпты — как блоки команд с приглашением >. Плотность данных и есть эстетика.
