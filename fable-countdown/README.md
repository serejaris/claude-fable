# Fable Countdown — до 22 июня

Chrome-расширение, заменяющее новую вкладку обратным отсчётом до полуночи 22 июня 2026 — дня, когда Fable 5 выходит из подписки. Каждый новый таб — напоминание: время с ней ограничено, используй по максимуму.

![screenshot](screenshot.png)

## Что внутри

- **Огромный счётчик** в стиле memento mori — дней до дедлайна. Клик по числу переключает единицы: дни → часы → минуты → секунды.
- **Сетка углей** — одна точка = один час с моделью. Прошедшие гаснут, текущий час тлеет янтарным.
- **Lifeline** — тонкая полоса вверху: сколько отведённого окна уже сгорело (отсчёт от первого открытия).
- **Эпиграф дня** — меняется раз в сутки. **Подсказка** — случайная на каждый таб, что выжать из модели сегодня.
- После полуночи 22 июня страница переходит в пепельный режим: «Спасибо. Это было хорошо.»

Работает полностью офлайн: без сети, без аналитики, без зависимостей. Шрифты системные (Didot / Bodoni 72 / SF Mono на macOS).

## Установка

1. Открой `chrome://extensions`
2. Включи **Developer mode** (тумблер справа вверху)
3. **Load unpacked** → выбери папку `fable-countdown/extension/`
4. Открой новую вкладку

## Структура

```
extension/
├── manifest.json    MV3, chrome_url_overrides.newtab
├── newtab.html
├── newtab.css       тёплый чёрный / костяной серф / янтарь
├── newtab.js        отсчёт, сетка часов, эпиграфы
└── icons/           сгенерированы скриптом (уголёк + дуга)
```
