# Fable Countdown — до 22 июня

Chrome-расширение, заменяющее новую вкладку обратным отсчётом до полуночи 22 июня 2026 — дня, когда Fable 5 выходит из подписки. Каждый новый таб — напоминание: время с ней ограничено, используй по максимуму.

![screenshot](screenshot.png)

## Что внутри

- **Огромный счётчик** в стиле memento mori — дней до дедлайна. Клик по числу переключает единицы: дни → часы → минуты → секунды.
- **Сетка углей** — одна точка = один час с моделью. Прошедшие гаснут, текущий час тлеет янтарным.
- **Lifeline** — тонкая полоса вверху: сколько отведённого окна уже сгорело (отсчёт от первого открытия).
- **Эпиграф дня** — меняется раз в сутки. **Подсказка** — случайная на каждый таб, что выжать из модели сегодня.
- **Лимиты подписки** — в правом верхнем углу: 5-часовое окно сессии и недельное окно (% и время сброса). Янтарная подсветка с 60%, горячая — с 85%. Требует локального helper'а (см. ниже); без него блок просто скрыт.
- После полуночи 22 июня страница переходит в пепельный режим: «Спасибо. Это было хорошо.»

Работает полностью офлайн: без сети, без аналитики, без зависимостей. Шрифты системные (Didot / Bodoni 72 / SF Mono на macOS).

## Установка

1. Открой `chrome://extensions`
2. Включи **Developer mode** (тумблер справа вверху)
3. **Load unpacked** → выбери папку `fable-countdown/extension/`
4. Открой новую вкладку

## Helper лимитов (опционально)

Chrome-расширение не умеет читать Keychain, поэтому лимиты отдаёт крошечный локальный сервер (python stdlib, без зависимостей). Он берёт OAuth-токен Claude Code из Keychain, опрашивает `api.anthropic.com/api/oauth/usage` (кэш 3 мин, stale-фоллбек при rate limit) и отдаёт расширению только проценты и время сброса на `http://127.0.0.1:46123/usage` — токен наружу не выходит.

```bash
./helper/install.sh   # ставит launchd-агент com.fable.usage (автозапуск при логине)
```

Снести: `launchctl unload ~/Library/LaunchAgents/com.fable.usage.plist && rm ~/Library/LaunchAgents/com.fable.usage.plist`

## Структура

```
extension/
├── manifest.json    MV3, chrome_url_overrides.newtab + host_permissions 127.0.0.1
├── newtab.html
├── newtab.css       тёплый чёрный / костяной серф / янтарь
├── newtab.js        отсчёт, сетка часов, эпиграфы, лимиты
└── icons/           сгенерированы скриптом (уголёк + дуга)
helper/
├── usage_server.py  локальный сервер лимитов (Keychain → /api/oauth/usage → JSON)
└── install.sh       установка launchd-агента
```
