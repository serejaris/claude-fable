# claude-fable

Sandbox for live experiments with **Fable 5** — Anthropic's latest model (`claude-fable-5`).

Built during the stream: [youtube.com/live/eguZQ4MAh8U](https://youtube.com/live/eguZQ4MAh8U?feature=share)

## What's Here

Each subfolder is an isolated experiment — a separate idea, prompt, or mini-project tested with Fable 5. The root never contains work files; everything lives in its own `<slug>/` directory.

## Structure

```
claude-fable/
├── README.md
├── CLAUDE.md          ← agent instructions
└── <project-slug>/
    ├── prompt.md      ← original prompt verbatim
    └── ...
```

## Model

All experiments use `claude-fable-5` — the latest Fable model from Anthropic.
